# @openrent/storefront

## 1.0.0

### Minor Changes

- Consent-aware analytics: view_item, add_to_cart, begin_checkout and purchase events for GA4, Meta Pixel and Plausible, sent only after the visitor allows analytics.
- Dutch: admin, storefront, all seven themes, emails, text messages and documents.
- Prices can be shown in other currencies (rates by hand or from the ECB), marked approximate, with a switcher in the storefront; tax-inclusive or exclusive display per language. Orders are charged in the shop's currency.
- Themes dress the embeddable widget (widget.css) and declare extension points; plugins add home page section types that show in the section editor (theme API 1.8, plugin API 1.7).
