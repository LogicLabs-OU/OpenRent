E-invoices in Peppol UBL, Factur-X / ZUGFeRD and the Estonian e-arve for companies whose billing details ask for them, with the shop's registry code and bank account on invoices. Signing through Documenso or DocuSign, with the signed PDF kept. ID checks through Stripe Identity or Veriff, started when the booking is reserved. Orders made by staff print the customer's default billing details, and the billing details dialog opens again for new details.
