The OpenRent plugin for WordPress (blocks and shortcodes for a product, a category and a book button; OpenRent sign-in or a publishable key) and the OpenRent app for Shopify (theme app blocks, and a small server that installs the app and connects the shop with OpenRent sign-in). `GET /api/v1/tenant` now also gives the storefront's address. Long-term support from 1.4 on, a compatibility matrix of plugin and theme API versions, and an RFC process for changes others build on.
