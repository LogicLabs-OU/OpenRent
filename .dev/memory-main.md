# Purpose

This file is used to store the coding agent's long-term memory of the project. When asked to append new memory to this project, following the following structure:

- Use h2 for a summary of the current session, be breif and descriptive
- List all the facts that you have learned about this project during this session. If the facts are already given to you in the PRD or was previously recorded in thie memory file, you don't need to repeat it.
- This is not a summary of what you have done, it is about what you have found and what the future dev should know about this codebase
- Only record new facts about project sturcture, special cases we have implemented, and anything else you find will be helpful to future developer of this project.
- Explaining code that you think will be diffult to understand in the future. But don't explain code that are straitforward to understand. Only tricky ones.
- Keep each memory with an empty line for separation.
- Don't be too wordy, this is for information and only crucial infomration is needed.
