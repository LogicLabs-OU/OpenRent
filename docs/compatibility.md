# Compatibility

Which plugin API and theme API each OpenRent release provides. Made by `scripts/compat-matrix.ts`; do not edit by hand.

A plugin's `compat` range and a theme's `api` range are checked against these. Minor versions only add things: a plugin for plugin API 1.10 works with every later 1.x release, and a theme for theme API 1.10 likewise. Long-term support releases keep their API versions for their whole support time.
